# Andrei Ziber — Portfolio

A clean, light, responsive portfolio built with React, TypeScript and Vite.

## Included

- Home page
- Projects directory
- Project case studies for JobPilot, VEO Digital Twin, Sola, interactive systems and an IoT data pipeline
- About page
- CV page with browser print / Save as PDF
- Contact page
- Responsive mobile navigation and layouts

## Run locally

Requirements: Node.js 20+ recommended.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The generated static site is in `dist/`.

## Deployment

This is a static frontend and does not need the JobPilot backend to run. It can be deployed to a static hosting service such as Cloudflare Pages, Netlify or Vercel. Keep the current Tilda site live until the new site has been reviewed and the new URL is ready.

## Before publishing

1. Replace `REPLACE_WITH_YOUR_EMAIL` in `src/App.tsx` with your verified email address.
2. Replace the CV draft with exact experience titles, employers, dates, and verified outcomes.
3. Add a downloadable, verified PDF CV if desired.
4. Add confirmed demos, screenshots, videos and repository links for each project.
5. Confirm the education programme wording and dates.
6. Review all copy and links on mobile and desktop.

## Accuracy note

Project pages intentionally avoid unverified metrics and claims. JobPilot’s case study is based on its README-level architecture. VEO and other case studies are draft summaries and should be checked against the current repositories and original project files before publication.
